# Heritage Explorer Quest

Create a fully animated, immersive, game-like landing page for an Indian History & Culture exploration website.

The website should NOT look like a normal educational website or a simple collection of cards.

It should feel like the user has entered an interactive Indian heritage game world.

CORE CONCEPT

The user is a Heritage Explorer entering a magical interactive map of India.

The landing page should immediately communicate:

“Explore India. Discover its history. Unlock its culture.”

The entire page should feel alive. Elements should continuously move subtly, react to the cursor, animate on hover, and transition smoothly as the user explores.

Avoid static layouts wherever possible.
